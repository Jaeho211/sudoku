# 스도쿠 탐험
어린이가 실제 퍼즐에서 풀이 방법을 발견하는 모바일 웹앱.

## 실행
Node.js 22 이상. 외부 의존성 없음.

```
npm ci
npm run dev
npm test
npm run build
```

개발 주소: http://localhost:5173. 정적 배포 디렉터리: `dist`. Cloudflare Pages에서는 빌드 명령 `npm run build`, 출력 디렉터리 `dist`를 사용한다. Workers Static Assets는 `wrangler.jsonc`를 사용한다.

## 기능
- 10개 학습 스테이지: 6×6 설명 예제 → 실제 6×6 완성 → 9×9 설명 예제 → 쉬운 9×9 완성.
- 순서대로 클리어, 완료 단계 다시 풀기, 진행 기록과 최근 학습 문제 저장.
- 모두 클리어하면 자유 문제 모드의 9×9 해금. 기존 6×6 저장 유지.
- 6×6(2×3 상자) 및 9×9(3×3 상자), 유일해와 두 기법으로 완주 가능성 검사.
- 단계별 힌트, 후보 메모, 충돌 표시, 되돌리기, PWA 오프라인 지원.
- 시간 제한 및 생명 차감 없음.
