# 스도쿠 탐험 설계

## 목적과 흐름
어린이가 풀이 방법을 배우고 스테이지를 차례로 클리어해 9×9 문제 풀기로 연결한다. 시간 제한이나 생명 차감은 없다.

## 스테이지
| 단계 | 내용 | 완료 조건 |
|---|---|---|
| 1 | 6×6 한 칸의 유일 후보 | 목표 칸의 정답 입력 |
| 2 | 6×6 가로줄의 유일 자리 | 목표 칸의 정답 입력 |
| 3 | 6×6 세로줄의 유일 자리 | 목표 칸의 정답 입력 |
| 4 | 6×6 상자의 유일 자리 | 목표 칸의 정답 입력 |
| 5 | 실제 6×6 한 판 | 모든 칸 완성, 중복 없음 |
| 6 | 9×9 한 칸의 유일 후보 | 목표 칸의 정답 입력 |
| 7 | 9×9 가로줄의 유일 자리 | 목표 칸의 정답 입력 |
| 8 | 9×9 세로줄의 유일 자리 | 목표 칸의 정답 입력 |
| 9 | 9×9 상자의 유일 자리 | 목표 칸의 정답 입력 |
| 10 | 쉬운 9×9 한 판 | 모든 칸 완성, 중복 없음 |
| 11 | 후보 숫자 적기 | 목표 칸의 가능한 숫자 모두 메모 |
| 12 | 후보가 하나인 칸 | 후보 메모를 보고 정답 입력 |
| 13 | 후보 속 상자의 유일 자리 | 정답 입력 |
| 14 | 후보를 보며 12칸 이어 풀기 | 안내받으며 후보 변화와 다음 칸 확인 |
| 15 | 가로줄 후보 비교 | 후보 속 유일한 자리 입력 |
| 16 | 세로줄 후보 비교 | 후보 속 유일한 자리 입력 |
| 17 | 후보로 쉬운 한 판 | 24칸 완성, 기본 두 방법만 사용 |
| 18 | 상자와 줄: 준비된 보드, 후보 하나 제거 | 목표 후보 1개 제거 |
| 19 | 상자와 줄: 준비된 보드 반복 | 목표 후보 모두 제거 |
| 20 | 상자와 줄: 원래 보드 적용 | 목표 후보 모두 제거 |
| 21 | 후보를 보며 기본 한 판 복습 | 40개 빈칸 완성 |
| 22 | 후보 쌍: 준비된 보드, 후보 하나 제거 | 목표 후보 1개 제거 |
| 23 | 후보 쌍: 준비된 보드 반복 | 목표 후보 모두 제거 |
| 24 | 후보 쌍: 원래 보드 적용 | 목표 후보 모두 제거 |
| 25 | 중급 퍼즐 마무리 연습 | 앞부분을 논리적으로 풀어 둔 보드의 마지막 12칸 완성 |
| 26 | 중급 9×9 한 판 | 두 제거 기법을 사용해 전체 완성 |

앞 단계를 완료해야 다음 단계가 열린다. 완료한 단계는 다시 할 수 있다. 10단계를 완료하면 문제 모드의 9×9가 열린다. 기존 10단계 완료 기록과 해금 상태는 유지한다. 스테이지 완료는 이해도 인증이 아니며 힌트 사용으로 진행을 제한하지 않는다.

## 설명 예제와 완성 문제
설명 예제는 관찰 → 근거 강조 → 결론 → 직접 입력을 제공한다. 목표 숫자와 칸의 오답은 입력하지 않고 구체적인 이유와 근거 숫자를 표시한다. 정답이면 “✓ 정답이에요!”, 이유, 다음 단계 버튼을 보여준다. 자동으로 넘어가지 않는다. 설명 예제에는 메모·지우기·되돌리기를 표시하지 않는다.

5·10단계는 전체 보드를 직접 푸는 실제 문제이다. 시작부터 목표 칸을 알려주지 않는다. 메모·지우기·되돌리기와 단계별 힌트를 사용할 수 있다. 자유 문제 모드와 동일하게 정답 대조로 즉시 오답을 표시하지 않고 규칙 중복만 표시한다. 유일해 퍼즐이므로 중복 없이 전체를 채운 경우 정답이다.

6×6은 1~6, 2×3 상자를 사용한다. 9×9은 1~9, 3×3 상자를 사용한다. 숫자 입력, 메모, 칸 위치, 상자 경계와 키보드 이동은 보드 크기에 맞게 바뀐다.

## 힌트와 문제 품질
힌트는 관찰 대상 → 근거 숫자와 제외 칸 → 결론과 이유 순서이다. 숫자를 자동 입력하지 않는다. 중복부터 수정하고, 중복 없는 오답으로 막혔으면 되돌리기를 안내한다.

전체 문제는 해가 하나이며 한 칸의 유일 후보 / 구역의 유일 자리만으로 완주 가능한지 생성 시 검사한다. 학습 예제는 검증된 보드를 숫자 치환해 사용하며 구역별 목표를 다시 계산한다. 따라서 예제를 생성하느라 반복 탐색하지 않는다. 스테이지 완성 문제는 적은 빈칸으로 시작해 첫 한 판의 부담을 줄인다. 난이도를 학년이나 이해도 점수로 판정하지 않는다.

## 저장과 기술
외부 의존성이 없는 JavaScript ES modules, 정적 호스팅, localStorage, PWA를 사용한다. 6×6·9×9 자유 문제는 따로 저장하며 기존 6×6 저장 데이터를 유지한다. 클리어 수와 가장 최근 학습 스테이지의 보드·메모를 저장한다. 홈으로 돌아가거나 재접속해도 이어서 할 수 있다. 되돌리기 이력과 힌트 설명 위치는 현재 세션에만 유지한다. 기록은 해당 브라우저에 저장된다.

## 다음 개선 후보
실사용을 보고 스테이지별 문제 수, 힌트 강조, 작은 화면의 9×9 입력을 조정한다. 더 어려운 9×9를 추가할 때는 후보 쌍 등 새 기법의 설명과 문제 품질 검사를 함께 확장한다.

## 시작 화면
상단의 탐험 카드에 26단계 진행과 다음 스테이지를 표시한다. 시작·이어가기·전체 완료 상태에 따라 주 행동 버튼이 바뀐다. 전체 스테이지 목록은 탐험 지도로 펼쳐볼 수 있다. 자유 문제는 홈에 6×6·9×9 카드로 직접 제공하며 9×9 잠금 상태와 해금 조건을 표시한다. 모드는 게임 화면에서 전환하지 않고 홈을 거쳐 이동한다.

## 중급 후보 훈련
11단계는 후보를 직접 메모하고 이후 후보를 자동 표시한다. 새 제거 기법마다 준비된 보드의 후보 하나 → 나머지 후보 → 원래 보드 적용을 반복한다. 준비 보드는 쉬운 정답을 미리 채우되 학습할 제거 패턴이 남아 있는지 매 입력마다 검사한다. 따라서 예제 전체를 푸는 부담 없이 같은 근거를 연습한다.

설명은 ① 근거 칸의 행·열과 후보 관찰 ② 반드시 성립하는 이유 ③ 제거 대상의 행·열과 숫자 순서로 펼친다. 근거 칸의 노란색과 제거 칸의 테두리를 구분하고, 후보를 지우는 행동과 답을 넣는 행동을 명시한다. 후보 쌍의 순서는 아직 확정할 수 없다는 점도 설명한다. 다음 설명 버튼으로 긴 설명을 나누어 볼 수 있다.

21단계는 기본 기법으로 해결되는 한 판, 25단계는 중급 문제의 마지막 12칸, 26단계는 두 제거 기법을 모두 요구하는 한 판이다. 25단계는 논리 풀이 이력으로 앞부분을 채우고 제거된 후보도 초기 메모로 보존한다. 마무리 연습 자체에서 두 기법을 모두 사용해야 한다고 요구하지 않는다.

전체 퍼즐의 후보 지우기는 현재 논리로 증명 가능한 제거만 허용한다. 후보 제거는 저장되고 되돌릴 수 있다. 숫자 지우기는 전체 후보를 다시 계산한다. 모든 단계의 유일해, 논리 완주, 제거의 안전성을 테스트한다.

기존 1~13단계 기록은 그대로 유지한다. 이전 22단계 과정의 14단계 이후 완료·진행 위치는 4단계 뒤로 옮긴다. 최초 16단계 과정 기록은 먼저 22단계 위치로 옮긴 뒤 같은 방식으로 변환한다. 9×9 해금 조건은 10단계 완료를 유지한다.

## 후보를 이용한 기초 풀이
후보 지우기 기법에 앞서 14~17단계에서 후보를 답으로 바꾸는 과정을 연습한다. 14단계는 12칸만 비어 있는 실제 퍼즐에서 한 칸씩 안내한다. 답을 입력하면 같은 구역의 해당 후보가 자동으로 없어지는 이유와 바뀐 칸 수를 설명하고, 다음 유일 후보 또는 유일 자리로 연결한다. 잘못된 입력은 반영하지 않는다. 15~16단계는 가로줄·세로줄의 후보를 비교한다. 17단계는 24칸을 스스로 채우며 막힐 때만 힌트를 본다.

14·17단계에는 후보 지우기를 쓰지 않고 후보가 자동 갱신된다. 두 퍼즐 모두 유일 후보와 유일 자리만으로 풀리는지 검사한다. 새 후보 제거 기법은 18단계에서 시작한다.
