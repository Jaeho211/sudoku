# 설계 v0.1

## 목적
규칙 강의를 생략하고, 이미 기본 규칙을 아는 어린이가 실제 풀이에서 논리적 방법을 발견한다.

## 모드
두 모드는 동일한 6×6 보드, 후보 계산, 충돌 판정, 논리 풀이 엔진을 공유한다.
학습 모드는 특정 기법의 한 수를 찾는 짧은 연습이다. 1단계(한 칸의 유일 후보) → 2단계(한 구역의 유일 자리). 각 단계는 관찰 대상 → 근거 강조 → 결론 설명 → 직접 입력 순서로 안내한다. 학습 입력은 목표 수를 확인하며, 자유 문제 입력과 구분한다.
문제 모드는 전체 보드를 완성한다. 정답과 대조해 즉시 오답 표시하지 않고 현재 규칙의 중복만 표시한다.

## 힌트
관찰할 대상 → 근거 숫자 강조 → 결론과 이유. 자동으로 정답을 입력하지 않는다. 중복이 있는 경우 먼저 수정하도록 한다. 중복 없는 잘못된 입력으로 논리 풀이가 막히면 입력 확인 및 되돌리기를 안내한다.
학습 모드의 다음 설명 버튼으로 근거와 결론을 순서대로 확인한다. 학습 완료는 이해도 인증이 아니다.

## 문제 품질
생성 시 해 개수 1을 확인하고 naked single / hidden single로 완주 가능한지 확인한다. 난이도는 빈칸 수가 아닌 필요한 논리 방법으로 정의한다. 현재 난이도 선택은 제공하지 않는다.

## 기술
의존성 없는 JavaScript ES modules, 정적 호스팅, localStorage. 입력 이력은 현재 세션에서 유지한다. 문제 및 메모는 재접속 후 복원하지만 학습 진행과 되돌리기 이력은 저장하지 않는다.

## 다음 개선 후보
실사용 관찰 후 힌트의 강조 방식, 연습에서 숫자 목표를 안내하는 방식, 반복 퍼즐 억제, 학습 기록 및 9×9를 검토한다. 후보 쌍과 상자-줄 추론은 별도 기법으로 추가할 수 있다.
